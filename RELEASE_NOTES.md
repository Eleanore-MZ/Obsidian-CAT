New lines now pair automatically even when the two notes are at different stages.

If you write several new lines in one note and then translate them one at a time, each translated line now links to the next untranslated line in the same place. Before, nothing linked until both notes had exactly the same number of new lines.

Install or update with BRAT using https://github.com/Eleanore-MZ/Obsidian-CAT
