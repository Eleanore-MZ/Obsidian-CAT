First release of CAT Highlight.

- Pair two notes and highlight the corresponding line or block in the other pane while editing (Live Preview and source mode).
- Units: lines, headings, list items, table rows, quote blocks and callouts.
- Pairings are stored invisibly in the plugin folder and follow edits, including inserted, deleted, rewritten, moved and split lines.
- Commands: pair, unpair, link the current line by hand, jump to the corresponding line, show pairing status.
- Settings: toggles for the highlight, the current-line tint, scrolling and the unpaired-line tint, plus colour and opacity for each.

Install with BRAT using https://github.com/Eleanore-MZ/Obsidian-CAT
