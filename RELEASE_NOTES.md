Draft marks.

- New command "Toggle draft on the current line (and its partner)". Assign it a hotkey under Settings, Hotkeys. It marks a line and its translation as a draft (for example, the translation is unfinished, or the source changed and the translation has not caught up). Running it again clears the mark.
- Draft lines are tinted in their own colour on both notes all the time, not only under the cursor. When the cursor highlight lands on a draft, both colours are layered.
- Drafts follow the lines through edits and disappear when a line is deleted.
- New command "Go to the next draft line" to walk through what still needs work.
- New settings: "Highlight draft lines" and a "Draft lines" colour with opacity (red by default).

Install or update with BRAT using https://github.com/Eleanore-MZ/Obsidian-CAT
