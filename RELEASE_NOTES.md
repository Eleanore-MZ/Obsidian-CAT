Translation mode, and a highlight that shows on every kind of block.

- New "Translation mode" button at the top right of each note (also available as a command). It opens the paired note in a split to the right. If the note has no pair yet, it creates a new note, pairs it, and opens it, so you can start translating straight away; each line you write pairs with the next source line in order.
- New settings for where those notes are created (same folder as the source, a dedicated folder, or the vault root) and how they are named ("{{name}} (translation)" by default).
- The highlight is now drawn as a translucent overlay, so it shows on quotes, callouts, inline code and anything else that has its own background. Table rows are tinted cell by cell.

Install or update with BRAT using https://github.com/Eleanore-MZ/Obsidian-CAT
